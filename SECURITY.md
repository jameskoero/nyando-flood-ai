# Security Policy

## Supported Versions
| Version | Supported |
|---|---|
| `main` (V2, the deployed API) | ✅ Yes |
| older commits, forks and V1 | ❌ No |

## Reporting a Vulnerability
Do not open a public GitHub issue for security vulnerabilities.
Email jameskoero@gmail.com with a description, steps to reproduce, and potential impact.
You will receive a response within 72 hours.

The threat model, the verified controls and the open items are in docs/SECURITY_BASELINE.md.
